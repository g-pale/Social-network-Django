# MiniSocial - Простая социальная сеть на Django

Простая, но функциональная социальная сеть на Django, созданная для образовательных целей и демонстрации возможностей Django и веб-технологий.

## Описание проекта

MiniSocial - это базовая социальная сеть, которая позволяет пользователям:
- Регистрироваться и входить в систему
- Публиковать текстовые посты (до 1000 символов)
- Прикреплять изображения к постам
- Ставить лайки на посты
- Оставлять комментарии
- Подписываться на других пользователей
- Просматривать персонализированную ленту новостей
- Обмениваться личными сообщениями
- Получать уведомления о действиях других пользователей
- Искать посты и пользователей
- Восстанавливать пароль через email

## Технологический стек

- **Python 3.10+**
- **Django 4.2**
- **SQLite** (база данных)
- **Bootstrap 5** (UI фреймворк)
- **Pillow** (работа с изображениями)
- **django-crispy-forms** (красивые формы)
- **python-decouple** (управление настройками)
- **WhiteNoise** (раздача статических файлов в production)

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd Social-network-Django
```

### 2. Создание виртуального окружения (рекомендуется)

```bash
python3 -m venv venv
source venv/bin/activate  # Для Linux/Mac
# или
venv\Scripts\activate  # Для Windows
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Создайте файл `.env` в корне проекта, скопировав `.env.example`:

```bash
cp .env.example .env
```

Затем отредактируйте `.env` и укажите свои значения.  
Для локальной разработки используйте `.env.example`, для production-профиля — `.env.production.example`.

### 5. Выполнение миграций

```bash
python manage.py migrate
```

### 6. Создание суперпользователя (для доступа к админ-панели)

```bash
python manage.py createsuperuser
```

### 7. Запуск сервера разработки

```bash
python manage.py runserver
```

Откройте браузер и перейдите по адресу: http://127.0.0.1:8000/

## Роли и разграничение доступа

В проекте реализована базовая ролевая модель, достаточная для учебного ТЗ:

1. **Гость (неавторизованный пользователь)**
   - Может просматривать общую ленту, профили и публичный контент.
   - Не может создавать посты, ставить лайки, писать комментарии, подписываться и отправлять сообщения.

2. **Пользователь (авторизованный)**
   - Может создавать и редактировать собственный профиль и контент.
   - Может работать с социальными функциями (лайки, комментарии, подписки, сообщения, уведомления).
   - Ограничен объектными правами: редактировать/удалять можно только свои посты и комментарии.

3. **Администратор / суперпользователь**
   - Имеет доступ к Django Admin (`/admin/`).
   - Может управлять пользователями, постами, комментариями, лайками, подписками, сообщениями и уведомлениями.

Технически это обеспечивается `@login_required`, проверками владельца объекта в `views.py` и встроенной системой прав Django Admin.

## Безопасность и профили запуска

Проект поддерживает два рабочих профиля: учебный (локальный) и боевой (production).

### Учебный профиль (локальная разработка)

Используйте для учебы и демонстрации:

- `DEBUG=True`
- `ALLOWED_HOSTS=localhost,127.0.0.1`
- SQLite
- `EMAIL_BACKEND=django.core.mail.backends.console.EmailBackend`

Проверка:

```bash
python manage.py check
```

### Боевой профиль (production)

Обязательные требования:

1. Установить `DEBUG=False`
2. Задать сильный случайный `SECRET_KEY` в `.env`
3. Заполнить `ALLOWED_HOSTS` реальными доменами
4. Работать только через HTTPS
5. Использовать production-БД (рекомендуется PostgreSQL)
6. Настроить безопасное хранение медиа-файлов и права доступа

Быстрый старт production-профиля:

```bash
cp .env.production.example .env
```

После копирования обязательно замените:
- `SECRET_KEY`
- `ALLOWED_HOSTS`
- SMTP-параметры (`EMAIL_HOST_USER`, `EMAIL_HOST_PASSWORD`, `DEFAULT_FROM_EMAIL`)

Проверка боевой конфигурации:

```bash
python manage.py check --deploy
```

Если команда показывает предупреждения, production-настройка считается неполной и не должна использоваться в публичном окружении.
