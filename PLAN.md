# План реализации проекта MiniSocial

## Обзор проекта
Простая социальная сеть на Django с функционалом постов, лайков, комментариев и подписок.

## Этапы реализации

### Этап 1: Подготовка и базовая структура проекта
**Цель:** Настроить окружение и базовую структуру Django-проекта

#### Задачи:
1. ✅ Создать структуру проекта Django
2. ✅ Настроить виртуальное окружение
3. ✅ Создать файл requirements.txt с необходимыми зависимостями
4. ✅ Создать .gitignore
5. ✅ Настроить базовые настройки Django (settings.py)
6. ✅ Настроить структуру приложений:
   - `accounts` - управление пользователями и аутентификация
   - `posts` - посты, лайки, комментарии
   - `followers` - система подписок
   - `core` - общие утилиты и настройки
7. ✅ Настроить MEDIA и STATIC файлы

**Результат:** Рабочий Django-проект с базовой структурой

### Этап 2: Модели данных
**Цель:** Создать все необходимые модели для работы приложения

#### Задачи:
1. ✅ Создать кастомную модель User (расширение AbstractUser)
2. ✅ Создать модель Post:
   - Поля: автор, текст (до 1000 символов), изображение (опционально), дата создания/обновления
   - Методы: __str__, get_absolute_url
3. ✅ Создать модель Like:
   - Связь ManyToMany или ForeignKey с Post и User
   - Уникальность (один пользователь - один лайк на пост)
4. ✅ Создать модель Comment:
   - Поля: пост, автор, текст, дата создания
5. ✅ Создать модель Follow:
   - Поля: follower (кто подписывается), following (на кого подписываются)
   - Уникальность пары (follower, following)
   - Защита от самоподписки
6. ✅ Настроить связи между моделями
7. ✅ Создать и применить миграции

**Результат:** Полностью описанная структура базы данных

## Технический стек

### Основные технологии:
- **Python 3.10+**
- **Django 4.x**
- **SQLite** (база данных)
- **Bootstrap 5** (UI фреймворк)
- **Pillow** (работа с изображениями)

### Дополнительные библиотеки:
- **django-crispy-forms** - красивые формы
- **crispy-bootstrap5** - Bootstrap 5 для crispy-forms
- **python-decouple** - управление настройками
- **Pillow** - обработка изображений
